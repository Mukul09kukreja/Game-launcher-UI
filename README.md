# Game Dashboard UI

A modern game launcher dashboard interface built with HTML and CSS featuring a blurred anime background and interactive navigation.

## 📋 Project Overview

This project is a stylish game dashboard UI that provides a clean, user-friendly interface for gamers. It features a navigation menu with multiple sections including Home, Store, Library, Stats, and Settings, showcasing popular games like GTA 5, Valorant, and League of Legends.

## 🎨 Features

- **Blurred Anime Background**: Fixed full-screen background with anime artwork and blur effect
- **Interactive Navigation Buttons**: Five main sections with hover and active states:
  - Home - Featured games section
  - Store - Purchase games
  - Library - Manage game collection
  - Stats - View player statistics
  - Settings - Configure preferences
- **Game Cards**: Display featured games with images (GTA 5, Valorant, League of Legends)
- **Smooth Transitions**: 0.2s transitions on button interactions
- **AMD Branding**: SVG icon for dashboard branding
- **Responsive Hover Effects**: Games lift up on hover for visual feedback

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Styling, animations, and visual effects
- **SVG** - Vector graphics for icons

## 🎯 Color Scheme

- **Navigation Buttons**: Magenta (`rgb(243, 4, 203)`)
- **Hover State**: Pink
- **Active State**: Red
- **Title Button**: Yellow
- **Game Cards**: Blue Violet
- **Text**: White (default), Black (on hover)
- **Title Bar**: Yellow with black text

## 🚀 How to Use

1. Open `index.html` in your web browser
2. Click on navigation buttons (Home, Store, Library, Stats, Setting)
3. Hover over game cards to see the lift effect
4. Click "Buy GTA 5" button to visit the Rockstar Games store
5. Interact with buttons to see color transitions (pink on hover, red on active)

## 📝 Notes

- Background image must be named `ANIME.jpg` and placed in the same directory
- Game images should be in the same folder as HTML file
- Navigation buttons use relative positioning for alignment
- All buttons feature rounded corners and smooth transitions
- Game cards have box-shadow for depth effect
