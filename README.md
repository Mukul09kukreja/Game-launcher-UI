# Game Dashboard UI

A modern game launcher dashboard interface built with HTML and CSS.

## 📋 Project Overview

This project is a responsive game dashboard UI that provides a clean, user-friendly interface for managing games. It features a navigation menu with multiple sections including Home, Store, Library, Stats, and Settings.

## 🎨 Features

- **Responsive Design**: Flexbox-based layout for flexible positioning
- **Interactive Buttons**: Hover and active states with smooth transitions
- **Navigation Menu**: Five main sections:
  - Home - Display featured games (GTA 5, Red Dead Redemption)
  - Store - For purchasing games
  - Library - Manage your game collection
  - Stats - View player statistics
  - Settings - Configure preferences
- **Brand Logo**: AMD-inspired SVG icon for branding
- **Smooth Animations**: 0.2s transitions on button interactions

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Styling and animations
- **SVG** - Vector graphics for icons

## 🎯 Color Scheme

- **Primary Button**: Magenta (`rgb(243, 4, 203)`)
- **Hover State**: Pink
- **Active State**: Red
- **Title Button**: Yellow
- **Text**: White (default), Black (on hover)

## 🚀 How to Use

1. Open `index.html` in your web browser
2. Click on any navigation button to interact
3. Hover over buttons to see the pink highlight effect
4. Click buttons to trigger the red active state

## 📝 Notes

- Button dimensions are standardized (100px width × 30px height)
- All navigation buttons have rounded corners (40px border-radius)
- Smooth transitions provide visual feedback for user interactions
